# Segwaelane Fresh Bakery Website

## 1. Project Overview
This website was created for WEBD511 - Web Development at The Independent Institute of Education.
The purpose of the website is to provide information about Segwaelane Fresh Bakery, showcase products, and allow customers to make enquiries online.

**Business Name:** Segwaelane Fresh Bakery
**Location:** Segwaelane, North West, South Africa

## 2. Website Structure
The website consists of 5 HTML pages that are linked together through a navigation menu:

| Page | File Name | Description |
| --- | --- | --- |
| Home | `index.html` | Landing page with welcome message and bakery highlights |
| About Us | `about.html` | Company history, mission and vision |
| Products | `services.html` | List of bakery products and prices |
| Enquiry | `enquiry.html` | Contact form for customer enquiries and orders |
| Contact | `contact.html` | Contact details, location and trading hours |

## 3. How to Run the Website Locally
**Method 1: VS Code Live Server - Recommended**
1. Open the `segwaelane-bakery` folder in VS Code
2. Install the `Live Server` extension
3. Right click `index.html` > `Open with Live Server`

**Method 2: Direct**
1. Open the `segwaelane-bakery` folder
2. Double click `index.html` to open in browser
